# 章节写作模板

通用底座 + 场景模块。所有表格后加"注：信息来源+截止日期"行；每章末视情况分页。

## 通用底座（七部分）

### 一、前言
三段式：① 报告目的与性质（按场景写：竞聘××法律顾问之用 / 服务于××专项决策参考 / 客户接洽前初步分析）+ 基于××资料包及公开渠道编制 + 不构成正式法律意见；② 法律依据清单（写全称+修订/施行日期+现行有效，按下表按场景选用）；③ 信息截止日期 + **尽调范围声明**（本报告核查范围覆盖目标公司及其存续分公司×家、各级控股子公司×家、控股股东××〔非自然人时〕；参股公司×家仅列示未排查；分诊未命中的延伸主体以汇总表呈现；超过范围的主体与境外主体的公开信息局限）+ 公开信息局限声明。

**常用法律依据库**（按场景选用，引用前必须回库核验原文与时效）：
- 通用：《公司法》（2023修订，2024-07-01施行）、《民法典》（2021-01-01施行）；涉延伸主体的常引条文——第13条（子公司独立承担责任/分公司责任由公司承担）、第178条（董监高任职禁止五种情形）、第265条（控股股东、实际控制人、关联关系定义）。**2023修订后条号已整体重排，禁止沿用旧法条号（如旧第14条分公司条款现为第13条）**
- 资本市场境内：《非上市公众公司监督管理办法》、股转《股票挂牌规则》、北交所《股票上市规则（试行）》
- 资本市场港股：《境内企业境外发行证券和上市试行管理办法》（证监会公告〔2023〕13号）、联交所《主板上市规则》
- 知识产权：《商标法》（2019修正）、《专利法》（2020修正）
- 食品/酒类：《食品安全法》（2021修正）、《商业特许经营管理条例》（国务院令第485号）
- 激励/税：财税〔2016〕101号、国家税务总局公告2014年第67号、《企业会计准则第11号——股份支付》
- 涉外：ODI（发改/商务核准或备案）、外汇37号文

### 二、公司基本情况
1. 工商基本信息表（四列式：项目|内容|项目|内容）；
2. 历史沿革表（时间|事项|内容，提炼变更记录为叙事节点，股权重组单列）；
3. 股权结构表 + 实际控制人认定段（穿透路径写清，未直接持股的说明认定口径，疑似亲属关系标【待尽调核验】）；**控股股东为非自然人的**，增加"控股股东基本情况表"（项目|内容四列式：名称、统一社会信用代码、企业类型、成立日期、注册资本/实缴、登记状态、参保人数、股东/合伙人构成、对外投资家数、功能定位）+ "控股股东向上穿透路径表"（层级|主体|持股比例|备注），并在认定段写明《公司法》第265条认定口径；
4. 董监高表（姓名|职务|任职起始|持股与兼任情况〔含兼任分公司负责人/子公司法定代表人〕），治理结构现状评价段（对照目标市场要求）；
5. **尽调主体清单表**（序号|主体名称|类型〔分公司/子公司/控股股东〕|持股比例及层级路径／分公司负责人|注册资本|成立日期|登记状态|功能定位|排查深度〔全维度/分诊〕）——与中间文件 JSON 一致，清单内每一主体在第四章必须有对应结论；另列"参股公司表"（企业名称|持股|注册资本|成立日期|登记状态|备注），注明仅列示未做全维度排查；已注销/吊销的分公司与子公司不入此表，入历史沿革表并注明注销/吊销日期。

### 三、主营业务与经营资质
主营与模式（官网+媒体报道+经营范围三角验证）；行业资质清单核查（许可持有情况逐项标"已持有/【待核验】"）；主要客户与供应商（如有）。

### 四、法律风险事项初步梳理
诉讼仲裁表（涉及主体|案件|案号|公司方地位|标的与进展）、行政处罚表（涉及主体|处罚机关|事由|结果|日期）、知识产权（持有主体逐项标注）、劳动社保（各主体参保人数对照）、疑似关联企业排查结论。**所有风险表设"涉及主体"列**，子公司、分公司、控股股东的记录不得混记在目标公司名下。

新增 **4.x 延伸主体核查结论表**（主体名称|类型|分诊结果〔命中维度与条数／均无记录〕|重点发现|风险等级|建议）——《尽调主体清单》逐主体一行，全维度排查的主体在表后以小节展开（基本情况→风险发现→对目标公司的传导路径→建议），分诊无命中的一行结论即可；非自然人控股股东的结论须单列小节，重点写所持目标公司股权状态（出质/冻结）、自身信用与同业竞争三项。

### 五、重点法律问题初步发现
汇总表（序号|涉及主体|问题事项|风险等级|初步建议），高优先级问题逐一专项说明（问题—依据—影响—可执行建议）；延伸主体的问题在"影响"段写清向目标公司的传导路径（合并报表/担保责任/控制权稳定/资产完整性/任职资格）。

### 六、初步建议与下一步工作
按近期（1—3月）/中期（3—12月）/远期分层；末尾一段本所可提供的服务清单（竞聘场景）或工作方案（专项场景）。

### 七、声明与限制 + 签署页
标准5条（公开信息局限/法规时效/第三方数据口径/不构成正式意见/仅供内部参考）；签署页单独成页分页符分隔：上海市锦天城（深圳）律师事务所，经办律师：李成，落款日期（中文大写）。

## 场景模块A：资本市场竞聘

### A-1 资本市场路径回顾与评估
- 前次挂牌/上市记录：见微项目库+公告库双查（转板公司 otc 库也要查），无记录则明确写"无历史包袱"；
- 路径评估四要素：①架构选择（境内：挂牌→北交所，或直接IPO，测算报告期存续年限；境外：H股 vs 红筹，含ODI/37号文/负面清单核对）；②备案/审核义务（证监会境外备案或境内审核）；③上市条件对照（财务测试以现行规则原文为准）；④时间表倒排（现实预期，不迎合客户"明年上市"的乐观口径）。

### A-2 同行业上市公司分析（法律视角）
- 可比公司表5家左右（公司|代码|交易所|主营|可比性），**优先与目标市场同板块**；
- 五至七个法律维度，每维度四层递进：行业共性 → 审核实践 → 典型案例（真实引证：代码/案号）→ 对本项目的启示；
- 末尾汇总对照表（关注维度|行业审核共性|目标公司对应情况|优先级）。

## 场景模块B：常法竞聘

### B-1 法律风险地图与服务需求识别
- 按风险清单排查结果，绘制"高频风险领域—具体表现—服务产品"对照表：合同管理（审查流程缺失）、劳动用工（社保/竞业/规章）、知识产权（权属归位/维权）、合规资质（许可补办/年报）、争议解决（在办案件应对）；
- 结论段：本所常法服务方案切入点（3—5条），落到客户痛点而非服务清单罗列。

## 场景模块C：专项前置（以股权激励为例，其他专项同构）

### C-1 专项法律分析框架
六步分析链，每步给"选项对比+推荐+依据"：
1. **主体选择**（在集团哪一层做：全资子公司层面激励的价值局限 vs 母公司层面的治理/融资/上市意义）；
2. **载体选择**（改造现有平台 vs 新设；GP 由谁担任及控制权归集）；
3. **股权来源**（增资 vs 老股转让——认缴未实缴时老股转让触发《公司法》88条责任，增资须227条全体放弃优先认缴）；
4. **定价**（平价/净资产/最近融资价；无外部融资时以产业方入股价为锚【待核验】；低价入股的股份支付与税务核定风险）；
5. **模式与条款**（平台+限制性份额 vs 期权 vs 虚拟股；成熟期cliff+分期；离职回购区分过错定价；保密/竞业/职务发明前置承诺）；
6. **税务与程序**（101号文递延纳税适用性——合伙平台间接持股【存在争议】须与主管税务机关预沟通；个人LP 5%—35%经营所得税负劣势；实施程序与文件清单表）。

## 表格设计速查

- 列宽**按每张表内容单独测算**，总和=14.64cm（A4默认边距版心）；序号/日期/金额/比例窄列（≤15%），长文本列 55%—68% 封顶防失衡；
- 尽调主体清单表列数多（9列）时字号降小五号、"持股比例及层级路径"列按实际路径长度分配并允许折行，"登记状态""排查深度"两列各≤8%；延伸主体核查结论表"重点发现""建议"两列合计不低于 55%；
- python-docx：tblLayout fixed + tblW + tblGrid gridCol 三处一致；外框1.5磅（sz=12）内框0.5磅（sz=4）；表头灰底D9D9D9居中加粗；
- 内容密集降小五号（9pt）；数字列右对齐、序号列居中；
- 生成后转 PDF 逐页检查文本块 maxx≤506pt，溢出即调列宽重生成。
