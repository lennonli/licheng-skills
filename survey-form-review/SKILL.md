# 董监高股东调查表复核

针对 IPO/新三板申报项目中的《自然人股东、董事、监事、高级管理人员及核心技术人员调查表》（docx，一人一份）做底稿级复核。核心原则：**机械规则交给脚本，判断与核查交给模型，公开信息交给MCP，股权数据以底稿为准**。同一批次多份表格一起复核时价值最大——夫妻、兄弟姐妹互填的内容可以相互印证。

## 第〇步：确认口径

1. **报告期起止**（如 2024-01-01 至 2026-08-31）；
2. **发行人全称**与**已知关联主体全称清单**（发行人、持股平台、子公司、主要机构股东）——用于名称一致性比对与MCP锚定，从项目指令（AGENTS.md）取；
3. **旧日期残留清单**（报告期刚延长时传旧截止日）；
4. **文件夹阶段语义**：如目录名为"待股东确认""待签署"，未签名/未填日期属预期状态，汇总时归入"定稿待办"而非问题。

口径在项目指令中已有的直接采用，没有的问用户。

## 第一步：本地规则校验（脚本）

```bash
python3 ~/.agents/skills/survey-form-review/scripts/check_survey.py \
    "<调查表文件或目录>" \
    --issuer "示例科技股份有限公司" \
    --period-start 2024-01-01 --period-end 2026-08-31 \
    --stale-dates "2026年6月30日,2026年1—6月" \
    --known-entities "示例科技股份有限公司,XX管理咨询中心（有限合伙）,XX管理咨询有限公司,XX投资有限公司" \
    -o "/tmp/<项目>-调查表复核-<YYYYMMDD>.json"
```

| 规则 | 内容 | 级别 |
| --- | --- | --- |
| R0 版本 | 同名多份文件并存（如"定稿"与"定稿(5)"），需确认基准版 | 高 |
| R1 报告期 | 定义句与项目口径比对；识别"至今"式与固定截止日式两种口径并提示统一；重复定义句；旧日期残留；调查范围说明句（报告期前12个月）勾稽 | 高/中 |
| R2 留空 | 姓名、身份证号码、学历、出生年月留空或填"/" | 高 |
| R3 身份证 | 18位校验位、出生段↔出生年月、性别位↔性别 | 高 |
| R4 教育 | 大中专以下记录（系本人最高学历时降为低）、起止到月、缺止时间、学历栏↔教育经历 | 中/低 |
| R5 工作经历 | 起止到月、月份留空（"1996年 月"）、末段须"至今"（否则报末段至报告期末空档）、**教育+工作合并覆盖找真空档**（>3个月；教育中断被工作覆盖不算）、全空→高 | 高/中 |
| R6 对外任职投资 | 仅填单位名其余栏留空（高，常掩盖真实持股任职）；控制企业无起止；申报无→MCP重点 | 高/中 |
| R7 近亲属 | 预印行留空；已填亲属证件留空/格式异常（11位疑似手机号；"已故/去世"放行）；以"见XX调查表"代替填写；控制企业须穿透下一级 | 中 |
| R8 勾选题 | 留空/未勾选（☑/√）；题干旧式起止日期 | 高/低 |
| R9 签署 | 签名、日期 | 高/中 |
| R10 批注 | 未处理批注统计 | 低 |
| R11 入股情况 | 持股子表入股时间到月、主体/出资/比例/抵押完整 | 中 |
| R12 一致性 | 持股主体/单位名称与已知主体全称比对（如"XX管理咨询有限公司"vs"XX管理咨询中心（有限合伙）"）；持股子表入股时间↔三表起始时间 | 中/低 |
| R13 跨表 | **批次内交叉核对**：A表近亲属子表所述"亲属N的企业"与N本人表三表比对——N未填报该企业（高，一方填错或漏报）、起始时间不一致（中） | 高/中 |

脚本自动跳过模板"/"行、Word临时锁文件；表型按表头关键词识别，遇到 unknown 表型时人工查看。JSON 落盘后读回使用，不重复解析原文件。

**脚本边界**：勾选符号仅认☑/√；同名多版本时跨表核对自动跳过该人（歧义）；"控制"栏含"共同控制"也按控制穿透；单位简称的最终判定靠MCP。

## 第二步：MCP公开信息核查

按 JSON 中每人的 `mcp_todo` 执行；同一企业多人表中出现只查一次。企查查涉及积分，**积分不足时不要停**，按下表降级：

| 核查维度 | 首选（企查查） | 降级（元典，免积分） | 元典无法替代时 |
| --- | --- | --- | --- |
| 单位全称 | `get_company_by_query` | `yuandian_rh_enterpriseSearch`（唯一命中即全称） | — |
| 企业股东/高管/对外投资/变更 | `get_shareholder_info` 等 | **`yuandian_rh_company_info`（一次返回股东详情+核心成员+投资详情+变更）** | — |
| 本人对外任职投资全景（人员维度） | `get_executive_related_companies` / `positions` / `investments` | 无 | 标【待核验·企查查充值后执行】，或改用天眼查skill |
| 已注销/历史企业 | `get_executive_historical_investments` | 元典库偏活跃企业，注销企业常查不到 | 同上 |

**元典数据质量提示**：股东信息可能混入历史股东（如同时显示已退出与新进股东），**以"变更记录"+"核准日期"为准**；关键事项建议再以国家企业信用信息公示系统复核一次。

### 2.1 单位名称全称
唯一命中→比对；多候选→列候选待确认；未命中→可能注销/个体户/简称，标【待核验】。

### 2.2 本人对外任职投资双向差异
MCP有表无=疑似漏报（高，关联交易/同业竞争线索）；表有MCP无=疑似已转让/注销或数据滞后（中，索要佐证）。比例逐字引用、禁止相乘穿透；冲突不判对错，标【待填表人确认】。

### 2.3 控制企业穿透
对本人及近亲属"控制=是/共同控制"的企业查对外投资：有控股子公司而表未填→中；顺带记录该企业**经营状态（注销/吊销）与风险标签（严重违法、经营异常）**——这直接影响五、其他情况中"曾任职企业破产清算/吊销"等问题的答案真实性，以及关联方风险披露。持股比例<50%却填"控制=是"的（如49%），提示核实控制依据。

### 2.4 入股情况勾稽
持股子表数据（主体/出资/比例/时间）：①与底稿（合伙协议/工商内档/股东名册/股权变动总结表）核对；②MCP查持股主体的合伙人名册，核对该自然人在册出资与比例（用比例×平台持股数反算表内"万股"数是否勾稽）；③**底稿未提供时明确提醒并列入【待底稿核对】，不出具"与底稿一致"结论**。入股时间口径（入伙平台日 vs 平台受让发行人股份日）全批次统一。

## 第三步：汇总输出

1. **总览**：份数、问题分布、本批次共性问题（如全部旧报告期、全部未签署）单列，不逐人重复；
2. **问题清单**按人分组，每条：级别｜规则｜位置｜问题｜可直接转发填表人的改法；并按性质标签：**[填表错误]**（可直接改）/ **[事实待披露]**（需进一步核查或披露，如报告期内股权变动、亲属企业严重违法）/ **[口径统一]**（全批次统一决策）；
3. **跨表与MCP差异表**；
4. **项目事实更新提示**：核查中发现的与项目指令（AGENTS.md）不一致的事实（如机构股东股权已变更），单独列出建议更新；
5. **【待底稿核对】/【待填表人确认】/【待核验】清单**；
6. 用户要求成文时出Word《调查表复核报告》（"调查表复核报告-日期-V1"）。

### 判定口径速查
- 留空≠"无"；"已故/去世"在证件栏视为合理填写；"见XX调查表"不算填写。
- 学历起点：大中专及以上；本人最高学历为高中及以下者填了该行，作低级口径提示。
- 连续性：教育+工作合并后无记录>3个月才报；末段非"至今"要报尾部空档。
- 报告期定义句：固定截止日式与"至今"式二选一，全批次统一。
- 级别：高=缺失/错误/漏报/矛盾，影响核查结论；中=需补充或确认；低=格式与口径提示。

## 常见坑
- Word拆run：文本按`w:t`拼接（脚本已处理）；
- 模板行填"/"与真留空不同：前者是"申报无"，后者才报留空；
- 夫妻互填最容易出错：一方复制另一方的行改错公司名（实测出现过配偶互填时一方复制对方行而写错公司名的情形）——R13会抓，但要提醒双方核对；
- 持股平台是否列入三表各人做法不一（有人列持股平台有人不列），批次内统一；
- 子公司（如发行人全资子公司）按须知不属"其他单位"，出现在三表且全"/"时建议删除并注明任职。
