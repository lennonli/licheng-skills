# 断语写法：从格局到人事

方法论解决"这盘是什么"，本文解决"那又怎样"。核心要求：**每一条断语都要能落到用户明天可以做的事情上。**

## 1. 日主取象

十天干的性情底色。写的时候取其**意象**，不要只贴标签。

| 日主 | 取象 | 性情底色 |
| --- | --- | --- |
| 甲木 | 参天之木 | 正直向上、要强、爱面子、宁折不弯、认死理 |
| 乙木 | 花草藤蔓 | 柔韧、能屈能伸、适应力强、善借力、外柔内刚 |
| 丙火 | 太阳 | 热烈外放、慷慨、光明磊落、藏不住话、有感染力 |
| 丁火 | 灯烛炉火 | 内敛温润、心思细腻、重感情、有韧性、表面随和内里主意正 |
| 戊土 | 城墙高山 | 厚重、稳、可靠、固执、不轻易变通 |
| 己土 | 田园之土 | 柔软含蓄、能容纳、务实细致、耐性好，但偏保守、易委屈自己 |
| 庚金 | 原矿刀剑 | 刚毅果断、执行力强、讲义气、有锋芒、需锻炼才成器 |
| 辛金 | 珠玉首饰 | 精致、审美好、重体面、有分寸；自尊极强、记性好、不易服人 |
| 壬水 | 江河大海 | 聪明机变、心胸开阔、能容人、善交际；好动、恒心偏弱 |
| 癸水 | 雨露溪泉 | 细腻、内敛、直觉准、有耐性；多思、易忧、不外露 |

**对照写法**：庚金"需要火来炼"，所以缺火的庚金命，一生的课题就是"缺一道把钢锻成器的火"——这个意象可以贯穿整篇报告，比反复说"官杀为用"生动得多。辛金反过来"畏丁火之炼、喜丙火之照"，同为金而取用有别，这类细处要写出来。

## 2. 十神的人事含义

给不懂命理的用户看时，**每个术语第一次出现要顺带解释**，用一句话，不要长篇。

| 组 | 十神 | 代表 |
| --- | --- | --- |
| 印 | 正印/偏印 | 母亲、长辈、庇护、学历、资源、内在支撑、房产 |
| 比劫 | 比肩/劫财 | 兄弟姐妹、朋友、同行、竞争者、分财者 |
| 食伤 | 食神/伤官 | 才华、表达、创造力、自我展现；女命亦为子女 |
| 财 | 正财/偏财 | 钱财、物质欲望、父亲；男命亦为妻 |
| 官杀 | 正官/七杀 | 上级、规矩、压力、名分、事业；男命亦为子女，女命亦为夫 |

**几组高频结构的现实含义：**

- **印重身滞**：被照顾得太好、路铺得太平，反缺自己闯的动力。表现为"想得多做得少、准备到完美却错过窗口、遇事先找人而不是自己扛"。对治是"少代劳、多放手、先做起来再调整"
- **财多身弱**："机会看得见吃不下"。摊子容易铺大但吃不下，宜一门做深、忌多点开花；且最忌合伙、担保、借贷扩张
- **比劫夺财**：破财的典型方式是"被熟人分走"。合伙、担保、代持、口头约定的资金往来是终身设防的口子
- **伤官见官**：与规矩、权威、上级天生易起摩擦。在讲科层的环境里吃亏，适合有专业门槛而非讲服从的路径
- **伤官旺而财弱**："才华多而变现少"。对治很具体——把想法做成可交付的东西：证照、作品、专利、有名分的职位
- **官杀混杂**：压力来源多而杂、无所适从。**身弱者主被压制、易遇消耗型关系；身旺者主责任重、是撑住的那一方**——两者含义相反，务必先看旺衰
- **食神被合**：有话不说、有委屈自己扛，长期积压。需要主动建立表达出口
- **无印**：缺缓冲垫、缺内在支撑、缺自我修复机制。压力直接打在身上。表现为"自信不足、把别人的评价看得太重"——这是结构使然，可以靠后天补
- **无官杀**：不受管束、极难被指挥。进讲科层讲服从的组织会很痛苦，这是结构决定的，不是态度问题

## 3. 性情：怎么写才不像算命摊

**分"长处"与"要留意的"两栏，后者写得比前者具体。** 好话谁都爱听但没有用，短处才是用户能拿去改的。

**每条短处配一个可执行的对治。** 例如：
- 印重则滞 → "此局最典型的失败模式不是做错，而是**没做**。把'想清楚再做'改成'先做起来再调整'"
- 伏吟主执念 → "识别到'我又在想这件事了'，本身就是解法"
- 不擅拒绝 → "最典型的困境是被各种'应该'填满，唯独没有自己"

**收一句"核心矛盾"。** 用一句话概括这个人一生的主要张力，形式是"不缺 A，不缺 B，缺的是 C"。这一句往往是全篇最被记住的：

- "不缺才华，不缺人品——缺的是把才华变成结果的那道出口"
- "是块好玉，但埋在土里——不缺质地，缺的是洗出来的那道水"
- "能扛能容、被人依赖了一辈子——最该学会的，是也让自己被照顾一次"

这一句要从**格局本身**长出来，不能套用。

## 4. 六亲与感情

按十神对应：印=母、财=父（男命亦为妻）、比劫=兄弟、食伤=子女（女命）、官杀=子女（男命）/夫（女命）。

**判断要点：**

- **该星是否透干、是否有根、是否为用神**。为忌神的六亲星，不等于关系不好，而多是"这段关系构成压力"或"助力有限"
- **看宫位**：年柱主父母与早年，月柱主父母兄弟与青年，日支为配偶宫，时柱主子女与晚年。**宫位被冲刑，该六亲之事有波折**
- **配偶宫的十神是判断另一半类型的主要依据**。日支为印，另一半多带照护型、文教型色彩，或年龄阅历略长；日支为杀，配偶性格强势；日支为财（男命），感情主动
- **空亡落在配偶宫或子女宫**，主"助力有名无实、易觉孤独"，但逢冲合则解

**婚期建议**：身弱、配偶星为忌、配偶宫被冲、官杀混杂——凡具其一，都倾向建议晚婚，并说明理由（不是迷信，而是"届时本人的底气与判断力会明显好于现在"这类可理解的逻辑）。要结合大运说：哪一步运之后遇到的对象质量与稳定度会更好。

**最有价值的一条往往不是"何时结婚"，而是关系模式的提醒**。例如伏吟主"容易重复同一种模式、栽在同一类人身上"；己土主容者"最容易犯的错是默默付出、指望对方看见，而这在婚姻里通常行不通"。

## 5. 健康

**原则：命理话语必须落到现实可操作的建议，且不替代就医。**

五行—脏腑对应：木=肝胆筋络眼，火=心血脉小肠，土=脾胃肌肉，金=肺大肠皮毛，水=肾膀胱泌尿生殖。

判断方法：**看哪个五行过旺、过弱、或受冲克，对应的脏腑就是薄弱环节**；再看大运哪一步会加重。

高频组合与落地建议：

| 命理特征 | 薄弱环节 | 落地建议 |
| --- | --- | --- |
| 火旺无水 | 心脑血管、血压血脂、眼目、易上火 | 忌酒忌辛辣、多喝水、忌熬夜、控制情绪、定期查血压血脂 |
| 水旺火弱 | 寒湿、循环差、泌尿生殖、畏寒 | 保暖、忌生冷、多晒太阳、规律运动出汗 |
| 木旺克土 | 脾胃消化、肝气郁结 | 忌生冷、规律作息、情志要有出口 |
| 土多晦火 / 湿土重 | 湿气重、代谢慢、身体沉重 | 祛湿为核心：忌甜腻、必须运动出汗、居所忌潮湿 |
| 金旺水寒 | 呼吸道、皮肤、肠道 | 保暖、注意呼吸道防护（幼儿尤须） |
| 自刑、伏吟、官杀克身而无印 | 情志、睡眠、内耗 | **表达出口比食补更要紧**：找人说、写下来、运动宣泄 |

**两条必须写清的分寸：**

1. **身旺者宜多动、宜出汗（泄气之正途）；身弱者宜温和持续，过量运动反是消耗。** 这一条对不同的盘建议相反，切勿套用同一句
2. **命理提示的薄弱环节较重时（尤其心脑血管），直接建议定期体检。** 不做具体疾病或时间的凶险断言

写健康部分时可以点明：命理说"缺火喜暖"，跟现代常识讲的"寒湿体质要保暖、要日照、要活动"，指向的是同一件事——**不必把它包装成玄学，它本身就有实际意义**。

## 6. 方位、行业与用色

顺用神而行。**特殊格局（专旺、从格）方向与常规相反，务必先确认格局再写这一节。**

| 五行 | 方位 | 颜色 | 行业 |
| --- | --- | --- | --- |
| 木 | 东 | 青、绿 | 文教、出版、设计、医药中医、林木、纺织、家具、环保、农业 |
| 火 | 南 | 红、橙、紫 | 教育培训、文化传媒、餐饮、能源电力、照明、电子、互联网、美容、演艺 |
| 土 | 西南、中部 | 黄、褐、米 | 房地产、建材、农业、仓储、中介、人力资源、保险、陶瓷玉石 |
| 金 | 西 | 白、银、灰 | 金融、法律、会计审计、机械、精密仪器、IT数据、医疗技术、鉴定评估 |
| 水 | 北 | 黑、深蓝 | 贸易流通、物流、传媒信息、咨询、旅游、水产、互联网 |

**居所与用色的建议要说清是辅助性的**，权重远低于后天努力。但方位与采光对身体确有实际影响（朝南干燥 vs 阴湿背光），这部分可以讲得实在些。

**比行业清单更有价值的，是"工作方式"的建议：**

- 杀印相生 → 靠专业与平台立身，规则越明确越讲资历越有利
- 伤官配印 → "既需才华又有资质门槛"的专业型职业（设计、法律、医疗、技术研发）
- 财多身弱 → 一门做深、细水长流，忌摊子铺大
- 身旺羊刃、比劫夺财 → 自己一手一脚做实、责权清楚，忌"拉几个兄弟一起干"
- 官杀混杂而身弱 → **最忌"多头受命"**，宜求专、稳、久，不宜求多、快、变
- 无官杀 → 自主、自立、不受制于人的路径；科层化组织会不适应

## 7. 儿童命盘：重心在教养

家长问孩子的八字，真正能用的是教养建议，不是三十年后的吉凶。**这一节要写成全篇最实用的部分。**

按格局给出教养方向，且**要说破"同一张盘，教养方式不同，结果完全不同"**：

| 格局特征 | 天性 | 教养核心 | 家长要克制的 |
| --- | --- | --- | --- |
| 伤官旺 | 聪明外露、逆反、锋芒盛 | **宜疏不宜堵**——讲道理、给才华出口 | 硬压、命令、发火 |
| 印重身滞 | 内敛、听话、想得多做得少 | **宜推不宜护**——少代劳、多放手、重行动 | 过度照顾、过度安排、替他做决定 |
| 身旺羊刃 | 刚烈、急躁、易冲突 | **要磨、要立规矩、要教会"忍"** | 用蛮力对硬（两边都刚只会两败） |
| 身弱官杀重 | 懂事、能忍、自信不足 | **补底气、教表达与拒绝** | 加压（本已过载，家里应是卸压的地方） |
| 财旺身弱 | 聪明但精力不足、易分心 | **重体质与作息，抓持续性** | 学业上过度施压 |

**几条通用要点：**

- **"服理不服压"的孩子（伤官旺、无官杀），讲清原因比命令管用十倍**
- **给才华出口**：伤官憋着会转成顶嘴叛逆，泄有其道才是才华
- **要有一项需要长期磨的训练**（武术、乐器、书法、棋类、长跑）——重点不在学什么，在于体会"忍住"的滋味。这对身旺刚烈的孩子价值最高
- **走忌神运的十年若恰在学业期，明确告诉家长这是结构性的**，不要在这十年给孩子下"不行"的结论。身弱又无印的孩子最容易被家人的评价定义，而他自己恰恰缺少反驳的底气
- **多子女家庭尤须提醒不要比较**：两个孩子先天结构与大运节奏可能完全不同，同龄段的表现天然不可比

## 8. 当下阶段建议

找出用户**正在走的那一步大运**（渲染器会自动高亮），单独写一段。这是整份报告时效性最强、也最容易被用到的部分。

写四件事：

1. **这一步运的性质**，以及它会以什么方式表现出来（"憋闷、施展不开、事情多而回报低"比"运势不佳"有用得多）
2. **是运还是人**——走忌神运时明确说"这不是能力问题"
3. **行事原则**：守还是攻、宜什么忌什么，具体到"忌合伙、忌担保、忌借贷扩张"这种程度
4. **下一个转折点在哪一年**，转过去之后是什么局面

若正处在换运之年（大运交脱），要单独点出——换运本身就主变动，工作、居所、生活重心的调整都在情理之中。

流年若与用神呼应，可以建议"宜在此年把关键的事定下来"。

## 9. 一页总结怎么写

放在最后，独立成块（渲染器会用深色底突出）。结构：

```
八字：… （出生信息）
日主：…——性情底色一句
旺衰：…（依据一句）
格局：…（病是什么、药是什么）
喜用：…　忌神：…
关键结构：三到五条，每条一行
大运：最好的时段 / 最需谨慎的时段 / 当下位置 / 转折点年份
性格：长处；但……
核心一句：…
六亲、健康、方位行业：各一行
```

**最后一句留给最要紧的提醒**，通常是"一生最需防的两件事"或"最该学会的一件事"。

## 10. 语气与边界

**要**：具体、可行动、坦率、有分寸、把坏消息说清楚同时给对治。

**不要**：
- 空泛吉凶（"事业有成""贵人相助"这类话没有信息量）
- 只挑好听的说
- 用玄学话语代替可执行建议
- 对死亡、重大疾病作时间上的具体断言
- 因命理结论劝人放弃医疗、法律或财务上的专业帮助
- 为改运兜售具体消费（法器、收费改名、风水采购）

**收尾的分寸**：命理管得了倾向，管不了选择。一份好的报告应当在最后把主动权交回给用户——**同一张盘，做与不做、疏与堵、忍与不忍，结果完全不同**。这句话不是客套，它是这门东西唯一诚实的结论。

若用户情绪明显低落，或把命理当作人生困境的唯一出口，**先关照人，再谈盘**；必要时建议与信任的人或专业人士谈谈。

## 11. 白话版：术语对照与写法

白话版放在报告最前面，写给不懂命理的读者。规矩见 `SKILL.md`「白话版」一节，这里给翻译工具。

**术语 → 白话**（同一个十神在不同处境下含义不同，按专业部分的判断选译法）：

| 术语 | 白话说法 |
| --- | --- |
| 身弱 / 身旺 | 自身底气偏弱、扛不动太多 / 底气足、精力旺，需要有地方使劲 |
| 喜用神 | 对她有利、能补短板的东西 |
| 忌神 | 对她不利、会加重负担的东西 |
| 印 | 专业本事、学历证书、长辈支持、靠得住的平台——「让人站稳的东西」 |
| 比劫 | 同辈、朋友、自己的力气；为忌时是「分走你东西的熟人」 |
| 食伤 | 才华、表达、点子；女命也指孩子 |
| 财 | 钱、机会、现实条件；也指父亲（男命也指妻子） |
| 官杀 | 压力、责任、规矩、上司；女命也指丈夫 |
| 财多身弱 | 机会看得见，精力接不住 |
| 官杀混杂（身弱） | 压力来源多而杂；容易遇到让自己付出过多的关系 |
| 杀印相生 | 压力能转成资历和本事 |
| 伤官见官 | 跟规矩、权威、上司容易顶 |
| 印重身滞 | 被照顾得太好，想得多、做得少 |
| 大运 | 每十年一段的大环境 |
| 流年 / 流月 / 流日 | 某一年的基调 / 一个月的节奏 / 哪几天适合谈事 |
| 走忌神运 | 时运逆风——不是能力问题 |
| 冲 | 变动、折腾 |
| 刑 / 自刑 | 摩擦、内耗、自己跟自己过不去 |
| 害 | 说不到一起、暗中的别扭 |
| 合 | 被牵住、放不下；也可能是助力 |
| 伏吟 | 同一类事、同一类人容易来两遍 |
| 空亡 | 看着有、实际靠不上 |
| 调候 | 冷热燥湿的平衡，可译成「身体和性情上偏燥 / 偏寒」 |
| 真太阳时 | 按出生地实际日照算的时间，西部地区比北京时间晚 |

**比喻怎么找**：从日主取象出发（第 1 节），把全局处境放进去。壬水被火土围困 →「一条河，流向很多，水源偏细」；甲木缺火 →「一块好木料，缺一道把它做成器的工序」。**一个比喻贯穿全篇，不要每段换一个。**

**写法要点：**

- **先结论，后原因。** 「这几年会比较累——不是你不行，是时运逆风」，不要先讲五行再给结论。
- **年龄和年份要具体。** 「38 岁之后的二十年最好」比「中晚年运佳」有用得多。
- **坏消息照说，配上做法。** 「容易铺太多摊子」后面紧跟「一门做深，宁少勿多」。
- **不用吓人的词。** 不写「凶」「劫」「克夫」「刑克」；写成「这段关系压力偏大，要注意……」。
- **收尾交还主动权。** 「命理只说倾向，怎么选、怎么做，结果会很不一样」——白话版里这句尤其不能省。

## 12. 「怎么办」：每段解读之后的建议与注意事项

规矩见 `SKILL.md`「每段解读之后的『怎么办』」一节。这里给写法示范与常见结构的对治清单。

### 正文与「怎么办」怎么分

| 写进正文（判断） | 写进「怎么办」（行动） |
| --- | --- |
| 财多身弱，机会看得见吃不下 | 手上的主线不超过两条；新机会来了先放下一条旧的再接 |
| 伏吟落配偶宫，易重复同一种关系模式 | 写下上一段关系里「不再接受」的两三条，遇到相似的人按清单判断 |
| 火旺缺水，心血管与睡眠为薄弱环节 | 23 点前睡；35 岁后每年查血压血脂 |
| 甲戌运为忌，压力多回报薄 | 不合伙、不担保、不借贷扩张；集中攒一个硬资质 |

**判断句的标志词**：「主」「易」「多」「倾向」。**行动句的标志词**：动词开头，带时间、数量或对象。

### 常见结构的对治清单

按专业部分的判断取用，不要整段照抄；结构不在原局就不写。

| 结构 | 对治 / 利用 |
| --- | --- |
| 身弱 | 讲节奏、不拼爆发；同一时期只扛一件大事；学会分工与求助 |
| 身旺 | 要有地方使劲：承担责任、做有挑战的事、规律运动出汗；忌闲 |
| 财多身弱 | 一门做深；忌合伙、担保、借贷扩张；机会先过「专业把握 / 可靠帮手 / 输得起」三问 |
| 比劫夺财 | 钱的往来写清楚、不做代持与口头约定；自己一手一脚做实，责权清楚 |
| 官杀混杂（身弱） | 求单一汇报线；拒绝多头受命；感情上警惕付出过多的关系 |
| 杀印相生 / 需印 | 考证、学历、职称、进规范平台；跟有资历的人学 |
| 伤官见官 | 选有专业门槛、不靠服从的路径；与上级沟通先讲依据再讲观点 |
| 伤官旺而财弱 | 把想法做成可交付的东西：证照、作品、专利、有名分的职位 |
| 印重身滞 | 先做起来再调整；给自己设截止日；少找人代劳 |
| 食神被合 / 无出口 | 建立固定的表达出口：写作、运动、定期倾诉 |
| 无印 | 主动给自己搭「缓冲垫」：稳定作息、一两个可依靠的人、应急储蓄 |
| 无官杀 | 选自主度高的工作方式；给自己定外部约束（截止日、合同、公开承诺） |
| 相冲 | 变动来临前预留余量（时间、资金）；冲开库时主动看新机会 |
| 相刑 / 自刑 | 内耗时用动作打断：运动、出门、换环境；识别「又在想这件事了」 |
| 相害 | 关键事项说清楚、写下来，不靠默契 |
| 伏吟 | 建立复盘习惯：同类问题第二次出现时，回看第一次是怎么发生的 |
| 合（绊住日主或用神） | 涉及人情与利益的决定设冷静期，隔夜再定 |
| 空亡 | 不把该宫位的助力算进底牌；自己留退路 |
| 合局成忌 | 行运补齐该局的那几年，提前收缩、不扩张 |

### 大运、流年的「怎么办」

- **大运**：一句定性（守 / 攻 / 收 / 养）+ 两三件具体的事。已过去的运写「怎么看待那段经历」，正在走的运最具体，未来的运写「提前准备什么」。
- **流年**：关口年写「避开什么、怎么把关」，窗口年写「这一年办什么」；平常年份不必逐一写。
- **流月、流日**：写成日程安排——哪几个月、哪几天适合谈事签约，哪些时段只做手头的事；提醒把日子记进日历。

### 喜用神的「怎么办」：翻译成生活选择

| 五行 | 生活里的「用」（不是消费） |
| --- | --- |
| 木 | 学习成长、读书、规划长期目标、与有朝气的人共事、多去户外 |
| 火 | 表达与展示、社交曝光、多晒太阳、温暖的作息与饮食 |
| 土 | 稳定的日程、长期承诺、积蓄、守信用、少换环境 |
| 金 | 专业与资质、规则与流程、决断、断舍离 |
| 水 | 交流与信息、流动与出行、思考与复盘、充足饮水与睡眠 |

忌神反过来写成「少做什么」：例如忌火即「少透支、少熬夜、少追热闹」，忌土即「少揽责任、少替人兜底」。
