## 1. 旺衰复核

脚本的 `strength.ratio` 是加权评分（月令权重 2.6，日支 1.6，其余 1.0/0.8），`verdict` 按阈值分五档。这只是起点，要按下面四条复核：

**（一）月令是不是决定性的？**
月令占全局力量的三到四成，但**月令为忌不等于身弱**。关键看月令之气有没有被转化。典型例子：庚金生午月（火旺金囚，本应失令），但若地支有申、酉成方，或有辰、丑湿土晦火生金，则失令而不弱，甚至身旺。

**（二）有没有通关之神？**
通关是全局最要紧的机关。土克水，中间有金则土生金、金生水，克变成生。木克土，中间有火则木生火、火生土，同理。**凡见通关，克我之神反成生我之源**，旺衰判断要整个翻转。杀印相生、伤官配印都是通关结构。

**（三）合化会不会改变力量？**
- 地支半合、三合、三会：会把参与的地支整体转化为局中五行。申子辰会水，则辰不再作土论。
- 天干五合：紧贴则合力强，遥合则弱。**合化能否成功，看月令是否生所化之神**——月令不生，则"合而不化"，只是彼此牵绊，各自力量仍在但被牵制。
- 化神真假直接影响旺衰：戊癸合化火，若生于午月则化得真，癸水从火，全局少一个水；生于子月则化不了，癸水仍是水。

**（四）根气的质量**
天干有没有根，比有几个同类更要紧。
- 通根本气（如甲见寅、卯）最实；通根中气次之；通根余气最虚。
- 库根（甲见未、丙见戌）平时不显，**逢冲则开，冲则可用**——所以辰戌丑未之间的冲刑，常常是好事而非坏事。
- 落在空亡之位的根，主"看着有依靠，实际使不上力"；但**逢冲逢合则空亡解，效力大减**。

## 2. 格局定性

先看月令本气透没透干：

- **月令本气透于天干** → 以该十神取格，格成得清晰。
- **本气未透，但中气/余气透干** → 以透出者取格。
- **全不透** → 以月令本气取格，格稍虚。
- **月令为比劫（建禄、月刃）** → 不取比劫为格，改看全局最旺、最有势的那个十神。

八格：正官、七杀、正印、偏印、食神、伤官、正财、偏财。

**格局定性之后，接着判两件事：**

**（一）格局是"喜"还是"忌"？**
正官、正印、食神、正财为吉神，宜顺用（护住它）；七杀、伤官、偏印、劫财为凶神，宜逆用（制它、化它）。但这只是起点——**身弱时七杀是负担，身旺时七杀是权柄**。同一个格局，旺衰不同，含义相反。

**（二）有没有救应？**
凶神有制有化，格局就成立；无制无化，就是病。常见的救应组合：

| 病 | 药 | 名目 |
| --- | --- | --- |
| 七杀攻身 | 印星化之 | 杀印相生 |
| 七杀攻身 | 食神制之 | 食神制杀 |
| 伤官旺而狂 | 印星制之 | 伤官配印 |
| 伤官见官 | 印通关，或财转化 | 伤官配印 / 伤官生财 |
| 财多身弱 | 比劫帮身、印生身 | — |
| 印重身滞 | 财星破印 | 财破印（此处财是药不是病） |
| 木多火塞 / 土多晦火 | 比劫帮身，或泄口疏通 | — |

**报告里要把"病"和"药"明确写出来**，一句话说清：病在哪、药是什么、药够不够、不够则靠什么补。这是整份报告的骨架，比任何断语都重要。

## 3. 特殊格局的辨析程序

这是最容易判错、且一错全错的地方。**从格与专旺格的取用与普通格局完全相反**——普通身旺要克泄，专旺格却要顺其势；普通身弱要帮扶，从格却要顺从旺神。判错一次，喜忌整个颠倒。

### 辨析必须逐条走完，任何一条不满足就不成格

**从强 / 专旺格（炎上、润下、稼穑、从革、曲直）**

| 条件 | 检查点 |
| --- | --- |
| 生于本气之月，或地支会成本气局/方局 | 三会 > 三合 > 半合，力量依次递减 |
| 天干透出同类 | 至少一位 |
| **无官杀有力克我** | 有一点而无根、或被合化，可视为不破；**有根有力则破格** |
| **无财星耗我（或极微）** | 财旺则破 |
| **无有力泄口** | 若食伤成势且通畅，则不必从，按普通身旺用泄 |

**从弱格（从财、从官杀、从儿）**

| 条件 | 检查点 |
| --- | --- |
| **日主全无根气** | 天干比劫、地支本气/中气/余气**一个都不能有**。哪怕藏一点劫财，也倾向不从 |
| **无印生扶** | 有印则日主有靠，不从 |
| **月令为所从之神** | 这一条最关键。月令不是所从之神，从势的根基就不牢 |
| **旺神未受制** | 若旺神被月令或他神克制（如官杀成群却被食伤或月令克），说明尚有抗力，不从 |

### 判不成格时，必须写明理由

例如："官杀五见成群、日主坐杀、火近乎为无，看似可从杀；但**月令是酉金食神而非木**，且**卯酉相冲、乙庚相合，旺神被压制两处**，寅中尚藏戊土劫财为根——三条否定，故不成从杀格，仍按身极弱取印比为用。"

把否定项逐条列出来，日后若发现结论与实际经历不符，可以直接回到这一步复核。**不写理由的改判是不可复核的，等于没判。**

## 4. 用神取法：扶抑

身弱 → 取**印、比劫**为用，忌财、官杀、食伤过重。
身旺 → 取**食伤、财、官杀**为用，忌印、比劫。

但要按下面三条细化，不能只看旺衰档位：

**（一）看病在哪，用神就治哪。**
同样是身弱，被官杀克得狠的，第一用神是印（化杀生身，一物两用）；被食伤泄得狠的，第一用神也是印（制食伤兼生身）；被财耗得狠的，第一用神是比劫（帮身任财，印反而生不动）。**"一物多用"的那个五行，永远排第一。**

**（二）看有没有已在位的药。**
药已在原局且够用的，不必再补；药在原局但分量不足的，就要靠大运补，且要在报告中说明"此命极度依赖大运"；药完全不在原局的，是全局最深的短板，要在方位、行业、生活方式上刻意补。

**（三）注意"已满不宜再加"。**
最常见的误判是机械套用古法。例如《穷通宝鉴》说"五月庚金专用壬水"，那是针对**火旺水少**的五月庚金；若原局壬水透干、子水在支、申中又藏壬，而火只有孤零零一个午还被冲——**药已经下够了，再下就过量**，此时水反而是忌神。

**判断"已满"的方法**：看该五行在 `wuxing` 加权统计中的占比，以及它要制的那个五行是否已被制得过头。

## 5. 调候：与扶抑冲突时怎么办

`chart.json` 的 `tiaohou` 字段给出《穷通宝鉴》该日干该月的古法调候用神，作为**参考**。

调候的原理是寒热燥湿的平衡：
- 生于亥子丑月（冬），金水寒冷，**需火解冻**，此时火的重要性可能压倒扶抑；
- 生于巳午未月（夏），火炎土燥，**需水润泽**；
- 生于寅卯月（早春）余寒未退，仍需火暖；
- 生于申酉戌月（秋），燥而肃杀，需水润。

**冲突处理原则：**

1. **两者一致** → 直接写"扶抑与调候双重印证，取用无分歧"，结论最可靠。
2. **调候之神恰是扶抑之忌** → 分量上取"微则可用、盛则为忌"。例如身弱而生于冬月，火为财耗身（扶抑忌）却为调候所必需——则天干见一点丁火可用，地支见午火成局则不利。要在报告中把这个分寸写出来。
3. **原局气候极端（无火或无水）** → 调候优先。一张滴水不见的夏月火命，或一张不见一点火的冬月水命，**气候失衡本身就是全局最大的病**，此时调候之神就是第一用神。

古法调候表是按典型情形编的，遇到原局配置特殊（如土厚木少 vs 木旺土虚同为二月己土），**要按实际配置调整，不能照抄**。照抄的迹象是：调候用神在原局明明已经过多，你还写"最需"。

## 6. 刑冲合害的实义

脚本给出事实，你要给含义。要点是**每一种关系都有两面**，只写坏的一面是不完整的。

**相冲**
- 坏：动荡、变故、不安定、所冲之宫位的六亲有波折
- 好：**冲开库门**。辰戌丑未皆为库，冲则中藏之物尽出可用。若库中所藏正是用神（如戌中丁火对冬金），这一冲是救命的
- 冲的是忌神则为吉（去忌），冲的是用神则为凶
- 年月冲主早年与家族；日时冲主自身、婚姻与子女

**六合**
- 合能羁绊，也能化。合住忌神是好事（如合杀），合住用神是坏事（如丙辛合把调候之丙火合走）
- 化神成立与否看月令，见第 1 节

**相害**
- 暗损，不显于外。多主隐性摩擦、期待错位、说不到一起
- 所害宫位对应的六亲关系需要经营

**三刑 / 自刑**
- 三刑主动荡、是非、内耗
- **自刑最典型的含义是"自己跟自己过不去"**——反复咀嚼、放不下、把压力往内收。落在日时两宫，主感情与子女之事上格外容易自寻烦恼
- 刑亦能开库，与冲同理

**伏吟**（两柱干支相同）
- 重复、循环、原地打转。同一类事经历两遍、同一个坎绊两次
- 落在配偶宫、子女宫，主该领域一波三折
- 性格上主执念重、事情过去了自己还在想

**三合 / 三会 / 半合**
- 三会力量最强（同方之气），三合次之，半合再次（且半合须带中神：子、午、卯、酉）
- **合成的局若是忌神，是全局最需警惕的结构**；若原局已有其二，行运补上其三而成局，那一步大运的吉凶会被显著放大
- 合局能改变旺衰判断，见第 1 节

**空亡**
- 所落宫位主"有名无实、得而复失"
- 逢冲、逢合则解，效力大减——**先查有没有冲合，再下结论**

## 7. 神煞的分量

神煞是**参考**，不作独立断语，更不能用来推翻五行生克的结论。用法是给已有的判断加一层色彩。

值得写进报告的：

- **天乙贵人**：第一吉星。在原局主人缘好、遇难有扶；原局不见而大运才见，写"贵人晚到"，这对判断人生节奏很有用
- **禄神**：自力得财、衣食有靠。禄在时支称"日禄归时"，主晚年有实权实利
- **羊刃**：性刚好胜、有魄力。身旺见刃则过刚易折，身弱见刃反是帮身之助
- **华盖**：清高好独处、近文史哲与传统学问。双华盖则此特征极明显
- **将星**：有主见、不甘居人下。与身弱并见时，形成"外柔内刚"的反差，很值得点出
- **驿马**：奔波变动、不宜久守一地
- **桃花**：人缘好、有魅力
- **金舆**：得配偶或家庭之实助
- **魁罡**（庚辰、庚戌、壬辰、戊戌日）：聪明果断、有权威；喜身旺，忌财官显露
- **空亡**：见上

**不要罗列一堆神煞充数。** 挑三到五个真正与全局判断呼应的写，其余略过。

## 8. 大运判吉凶

每一步大运要看四件事，**天干地支分开看，再合起来判**：

1. **天干**：是用神还是忌神？透出的十神与原局形成什么关系（是否合走用神、是否克制日主）？
2. **地支**：是用神还是忌神？**地支的分量重于天干**——天干为用而地支为忌，多是"心气高而条件不配"；地支为用而天干为忌，多是"事在往前走，人比较累"
3. **与原局的合冲刑害**：运支与原局四支的关系。尤其注意**是否与原局凑成三合/三会局**——这是大运吉凶被放大的主要机制
4. **是否填实空亡、是否冲开库门、是否引动伏吟**

`judge` 取值：大吉 / 吉 / 参半 / 平 / 需谨慎 / 不利。

**写大运判语的几条要领：**

- **点出转折点**。哪一年从滞转顺、哪一年由顺转紧，写清楚年份。这是用户最关心的
- **标出"一生最好的十年"和"最需谨慎的十年"**，各一段，讲具体
- **正在走的那一步要单独细写**，落到可操作的行事原则（守/攻、宜/忌）
- **走忌神运时明确说"这是运，不是能力问题"**。同时提醒：滞运期该做的是攒本钱（考证、积累专业、做出作品），不是搏一把——因为运转过来时，这些就是全部的本钱
- 早年运好而中年运滞的，说明"底子是实的，现在的困境是用不出来，不是没有"；早年滞而中晚年好的，说明"大器晚成，别在最难的阶段给自己下结论"

## 9. 改判时必须做的事

任何时候你的判断与脚本评分不一致——旺衰改判、不采纳算法档位、按特殊格局取用——**必须在报告的 `strength_reason` 或 `congge` 字段写明**：

1. 算法给的是什么
2. 你改成什么
3. 依据的具体条件（逐条列出）
4. 若与实际经历不符，可以从哪一步回头复核

这不是形式。命理判断本就有分歧，**一份可复核的报告才是负责任的报告**；把推导过程留下来，用户日后发现不对时能找到症结，而不是只能整份推翻。
